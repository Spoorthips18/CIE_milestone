# Cash Flow Management Dashboard – Design System

## 1. Design Overview

The Cash Flow Management Dashboard uses a soft, modern and minimal design. The interface is designed to help small business owners easily understand and manage their financial activities.

**Design Style:** Soft Modern  
**Theme:** Light Theme  
**Layout:** Clean, simple and responsive

## 2. Color Palette

| Purpose | Color | Hex Code |
|---|---|---|
| Background | Light Blue-Gray | `#f6f8fc` |
| Primary | Blue | `#5479e8` |
| Primary Light | Light Blue | `#eaf0ff` |
| Card Background | White | `#ffffff` |
| Card Border | Light Gray | `#e8edf5` |
| Main Text | Dark Slate | `#1e293b` |
| Secondary Text | Gray | `#718096` |
| Success | Green | `#16a37a` |

## 3. Typography

The dashboard uses a clean and readable sans-serif font style.

- **Main headings:** Bold, large text.
- **Section headings:** Semibold text.
- **Body text:** Regular-weight text.
- **Labels:** Small, medium-weight text.
- **Financial values:** Bold text for better visibility.

## 4. UI Components

### Navigation Bar
- Displays the application name.
- Provides links to Dashboard, Transactions and Payments.
- Highlights the currently active page.

### Buttons
- Primary buttons use the main blue color.
- Buttons have rounded corners.
- Hover effects provide visual feedback.

### Cards
- White background.
- Rounded corners.
- Light borders and subtle shadows.
- Used for financial summaries and dashboard sections.

### Input Fields
- Clear labels and placeholders.
- Simple borders.
- Consistent spacing and rounded corners.

### Badges
- Green for income or successful status.
- Red for expenses or overdue status.
- Orange for payments due today.
- Blue for upcoming payments.

## 5. Layout and Spacing

- Consistent spacing between sections.
- Rounded corners for cards and containers.
- Dashboard content uses a centered maximum-width layout.
- Flexible layouts are used to support different screen sizes.

## 6. Responsive Design

The interface should work on:
- Desktop computers.
- Tablets.
- Mobile phones.

Tables should support horizontal scrolling on smaller screens, and cards should adjust to the available screen width.

## 7. Design Principles

1. Keep the interface simple and easy to understand.
2. Highlight important financial information.
3. Use consistent colors and typography.
4. Maintain clear spacing between elements.
5. Provide visual feedback for user interactions.
6. Ensure readability across different screen sizes.
